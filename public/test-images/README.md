# Real X-ray test pair

These files are the AP and lateral views for the same documented hip-replacement case. The source page describes avascular necrosis of the left femoral head before replacement and postoperative views. They are supplied only to test image loading, view switching, zoom, pan, rotation, and display controls. They are not suitable for validating stress analysis or diagnosis.

- `bonevista-hip-ap-sample.jpg` — AP view. Source: [Wikimedia Commons file page](https://commons.wikimedia.org/wiki/File:X-ray_of_hip_with_total_arthroplasty_-_Anteroposterior.jpg).
- `bonevista-hip-lateral-sample.jpg` — lateral view. Source: [Wikimedia Commons file page](https://commons.wikimedia.org/wiki/File:X-ray_of_hip_with_total_arthroplasty_-_Lateral.jpg).
- Creator: Mikael Häggström, M.D. The source pages state that the images are dedicated under CC0 1.0 and record written consent for online publication.

The sample loader copies these static JPEGs into browser-local `File` objects. The app does not upload them to a server or infer measurements from them.
